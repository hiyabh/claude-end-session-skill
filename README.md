# 🛟 end-session — סקיל "סוף סשן" ל-Claude Code

כפתור גיבוי אחד שסוגר כל שיחת עבודה מול Claude Code בלי לאבד שום דבר.

חלק מקהילת **בין קודש לקלוד**.

## מה זה עושה

במקום לזכור לתעד, לעדכן יומן ולשמור גיבוי ידנית — אתה כותב **"סיימנו"** (או `/end-session`),
ו-Claude מריץ רצף סגירה מסודר:

1. **בדיקת בטיחות** — לא דורס שינויים שנעשו במקביל בערוץ אחר
2. **תמצית מצב** — איפה עצרת ומה הצעד הבא
3. **יומן מפורט** — מה נעשה, מה הוחלט ולמה, מה פתוח
4. **יומן שינויים** (CHANGELOG) — מה השתנה למשתמש, בעברית
5. **עדכון גרסה** — אם פרסת משהו
6. **רישום מרכזי** — שורה במאגר הפרויקטים + אימות שהגיבוי עלה
7. **זיכרון** — שומר תיקונים/דפוסים חדשים לפעם הבאה

כל שלב שלא רלוונטי — מדולג אוטומטית. הסקיל רץ **רק** כשאתה מבקש, לעולם לא באמצע עבודה.

## התקנה

### בלחיצת הדבקה (מומלץ)
פותחים את Claude Code ומדביקים:

```
הי קלוד! התקן לי בבקשה את סקיל "סוף סשן" (end-session).
1. זהה את הנתיב ~/.claude/skills/ (ב-Windows: C:\Users\<user>\.claude\skills\). צור אם חסר.
2. הורד: https://hiyabh.github.io/claude-end-session-skill/end-session-skill.tar.gz
3. חלץ את התיקייה end-session אל ~/.claude/skills/ — בלי לדרוס סקיל קיים.
4. אמת שהותקן והסבר לי איך להפעיל אותו.
```

### דרך הטרמינל
```bash
curl -L https://hiyabh.github.io/claude-end-session-skill/install.sh | bash
```

# 🛟 end-session — סקיל "סוף סשן" ל-Claude Code

כפתור גיבוי אחד שסוגר כל שיחת עבודה מול Claude Code בלי לאבד שום דבר.

חלק מקהילת **בין קודש לקלוד**.

## מה זה עושה

במקום לזכור לתעד, לעדכן יומן ולשמור גיבוי ידנית — אתה כותב **"סיימנו"** (או `/end-session`),
ו-Claude מריץ רצף סגירה מסודר:

1. **בדיקת בטיחות** - מוודא שלא דרסת שינויים שנעשו במקביל בערוץ אחר, ושואל אותך לפני שמאחדים היסטוריה שהתפצלה
2. **סידור התיקייה** - מוחק זבל טכני, מעביר קבצים מפוזרים לתיקייה הנכונה ונותן להם שם ברור. קובץ שלא ברור לאן הוא שייך עובר לתיקיית _לבדיקה, ושום דבר אחר לא נמחק
3. **תמצית מצב** - איפה עצרת ומה הצעד הבא, קצרה בכוונה כדי שתיטען מהר מחר
4. **יומן מפורט** - מה נעשה, מה הוחלט ולמה, ומה עוד פתוח (שום משימה מתוכננת לא נשכחת)
5. **קובצי ידע** - אם יש לך קובץ עובדות על העסק או על המשפחה, עובר על השיחה ומעדכן אותו בכל עובדה חדשה, עם מקור ותאריך. סתירה לערך קיים לא מוכרעת לבד אלא מוצגת לך כשאלה
6. **יומן שינויים** - מה השתנה למשתמש, בשפה של הפרויקט
7. **גרסה** - מעדכן מספר גרסה אם פרסת משהו
8. **גיבוי לפרויקט** - שומר ודוחף לגיטהאב ומוודא שהכול באמת עלה. אם אין עדיין ריפו, יוצר ריפו פרטי, אחרי סריקה שמוודאת שלא נדחפות סיסמאות או מידע אישי
9. **רישום מרכזי** - (לא חובה) אם יש לך קובץ מעקב אחרי כל הפרויקטים, מוסיף אליו שורה
10. **ריפו ההגדרות** - (לא חובה) אם תיקיית ההגדרות של קלוד שמורה בגיטהאב, מוודא שגם השינויים בה נדחפו
11. **זיכרון** - אם למד ממך משהו חדש, שומר אותו לפעם הבאה
12. **סוכנים ותהליכים** - עוצר סוכני משנה, משימות רקע ותהליכים שהסשן הפעיל ושכח (שרת פיתוח, דפדפן ברקע וכדומה), ולא נוגע בתהליכים שלך או של סשנים אחרים
13. **בדיקות אחרונות** - בפריסה ראשונה בודק שהקישור עובד ונראה טוב כשמשתפים אותו

כל שלב שלא רלוונטי — מדולג אוטומטית. הסקיל רץ **רק** כשאתה מבקש, לעולם לא באמצע עבודה.

## התקנה

### בלחיצת הדבקה (מומלץ)
פותחים את Claude Code ומדביקים:

```
הי קלוד! התקן לי בבקשה את סקיל "סוף סשן" (end-session).
1. זהה את הנתיב ~/.claude/skills/ (ב-Windows: C:\Users\<user>\.claude\skills\). צור אם חסר.
2. הורד: https://hiyabh.github.io/claude-end-session-skill/end-session-skill.tar.gz
3. חלץ את התיקייה end-session אל ~/.claude/skills/. אם כבר מותקן - העבר את הקיים לגיבוי ב-~/.claude/skill-backups/ (לא בתוך skills) והחלף.
4. אמת שהותקן והסבר לי איך להפעיל אותו.
```

### דרך הטרמינל
```bash
curl -L https://hiyabh.github.io/claude-end-session-skill/install.sh | bash
```
